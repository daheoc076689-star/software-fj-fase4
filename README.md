# Fase 4 - Software FJ

Este es mi código de Python para la Fase 4 de Programación

Es un sistema para gestionar clientes, servicios y reservas de la empresa Software FJ, sin usar base de datos. Todo se maneja en el código y los errores o eventos se guardan en un archivo de log para que el programa no se cierre cuando algo sale mal

Incluye clases, herencia, manejo de excepciones y una simulación de varias operaciones (buenas y con error) para probar que el programa sigue funcionando
